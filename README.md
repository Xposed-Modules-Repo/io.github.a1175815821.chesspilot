## 一、模块简介

ChessPilot 是一个 LSPosed 模块，用于**多邻国（Duolingo）国际象棋**练习：从棋盘读取实时局面（FEN），把 Stockfish 算出的最佳招法以箭头叠加画在棋盘上，并可选自动走棋。

模块本身**不含引擎**——引擎运行在配套的伴侣 App 里，两端通过回环 TCP 通信。所以模块体积很小，也不会给多邻国带来额外负担。

| 功能 | 说明 |
|---|---|
| 实时分析 | Hook 棋盘取得 FEN，引擎秒级给出最佳招法与胜率 |
| 推荐箭头 | 直接画在多邻国棋盘上：金色＝推荐招法，红色＝预测对手的应招 |
| 自动走棋 | 可选自动落子（延迟可调），或用悬浮窗按钮半自动确认 |
| 电脑算力 | 手机连电脑上的 Stockfish 19（NNUE），断线自动切回本地引擎 |
| 极限思考 | ponder：对手思考时预判其招法，命中则瞬时出招 |
| 狂暴模式 | 线程拉满 + 大内存，深算到底 |

## 二、环境要求

- 已 root，并安装 **LSPosed**（Zygisk）
- 多邻国 `6.85.7`（arm64）
- Android 8.1+（minSdk 27），模块作用域：`com.duolingo`

## 三、如何安装

1. 安装本模块 APK，在 LSPosed 中启用，**作用域只勾选「多邻国」**，然后重启手机
2. 安装**配套 App**（ChessPilot 伴侣 App），打开后点一次「启动引擎服务」，按提示授予通知权限
3. 进入多邻国开一局，棋盘上就会出现金色箭头

> 配套 App 不在本仓库。请到源码仓库的 Releases 下载：
> https://github.com/a1175815821/ChessPilot/releases/latest

## 四、常见问题

- **装完没反应**：确认 LSPosed 中作用域已勾选多邻国并重启；确认伴侣 App 的引擎服务正在运行（通知栏有常驻通知）。
- **多邻国升级后失效**：应用混淆名变动会导致 Hook 失效，需等待模块适配新版本。
- **能不能只用模块、不装伴侣 App**：不能，引擎在伴侣 App 里。
